# Discord Clone 🚀

A responsive UI clone of **Discord** built using **Vite**, **Tailwind CSS**, and modern web development best practices.

👉 **Live Demo:** https://discord-clone-two-puce.vercel.app

---

## 📸 Overview

This project replicates the modern interface and user experience of Discord, focusing on sleek layouts, responsive sidebars, dark theme styling, and clean visual elements across different screen sizes.

---

## ✨ Features

- **Modern Tech Stack:** Powered by Vite for fast bundling and hot module replacement.
- **Tailwind CSS:** Styled with utility-first CSS for responsive, pixel-perfect UI.
- **Responsive Design:** Adapts smoothly across mobile, tablet, and desktop views.
- **Dark Theme Interface:** Inspired by Discord's iconic dark theme design language.

---

## 🛠️ Tech Stack

- **HTML5** – Semantic layout structure
- **Tailwind CSS** – Styling and utility classes
- **Vite** – Fast development environment and bundler
- **Vercel** – Live deployment and hosting
